# 🌤️ Weatherly — Flutter Weather App

## 📱 About
Weatherly is a clean, feature-rich weather application built with Flutter. It fetches real-time weather data from WeatherAPI.com and 
presents it in a smooth, professional UI — covering everything from hourly forecasts and air quality to UV index and wind details.

## ✨ Features
### 🏠 Home Screen
##### Real-time temperature, condition & feels-like
##### Current date & time (location-based)
##### Hourly forecast with animated "Now" indicator
##### Today's weather highlights — Humidity, Wind, Pressure, Visibility, UV Index, Cloud Cover
##### Extended highlights — Max/Min Temp, Dew Point, Wind Gust, Chance of Rain/Snow
##### City search with live suggestions via bottom sheet
##### Notification badge in AppBar

### 📅 Forecast Screen
##### Multi-day weather forecast
##### Day-by-day breakdown with condition icons

### 🌬️ Air Quality Index (AQI) Screen
##### Circular pollutant indicators — CO, NO₂, O₃, SO₂
##### Particulate matter cards — PM2.5 & PM10 with descriptions
##### US EPA & UK DEFRA index cards with color-coded levels
##### Dynamic AQI description based on real data

### 🧭 Navigation
##### Custom bottom navigation bar with IndexedStack
##### Smooth tab switching — no route rebuilding
##### Active/inactive icon states with labels

## 🛠️ Tech Stack

| Layer | Technology |
|-----------|-----------|
| Framework | Flutter & Dart |
| State Management | Provider |
| Weather Data | WeatherAPI.com REST API |
| HTTP | http package |
| Image Caching | cached_network_image |
